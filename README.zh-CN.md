# Editor

[English](./README.md) | 简体中文

在思源里打开、编辑笔记链接到的文本文件。编辑器用你的思源代码字体与你选定的语法配色。

## 它做什么

思源把指向 `assets/` 下文件的链接当作普通超链接渲染，点击后交给系统默认程序——可能是个文本编辑器，也可能什么都没有。本插件把它改到思源里打开：一个带语法高亮、行号、搜索、补全、撤销与重做的独立页签。

三种入口：

- 点击资源文本文件的链接（默认开启接管时）。
- 右键链接，在「插件」子菜单里选「使用 Editor 打开」。
- 关掉接管，只用菜单入口。

只处理工作区 `assets/` 目录下的文件。指向工作区外绝对路径的链接（`file:///...`）不做处理。.sy 预览只处理工作区内的笔记文档。

## 环境要求

思源 3.8.3 及以上。

## 安装

市集安装：**设置 - 集市 - 已下载 - 插件**，搜索 Editor。

手动安装：把 `package.zip` 解压到 `<工作空间>/data/plugins/editor-siyuan/`，再启用。

## 格式化与压缩

操作条最右侧的「更多」里有两项：**代码格式化**与**代码压缩**。都作用于整篇正文，改动只进撤销栈、不落盘，`Ctrl+Z` 一次就能退回；预览模式下不可用。

笔记里的代码块也有这两项，在代码块右上角的 **更多 - 插件** 子菜单里，改的是那一个代码块，同样只进撤销栈。按代码块自己的语言判断能不能做：本插件没实现的语言（Python、Go 之类）不出现这两项，只读文档里出现但置灰。可以在设置里关掉。

| 语言 | 格式化 | 压缩 |
| --- | --- | --- |
| JavaScript | 是 | 是 |
| JSON / JSONC | 是 | 是 |
| CSS | 是 | 是 |
| TypeScript / TSX、SCSS、LESS、HTML / XML / Vue、YAML、Markdown | 是 | — |

格式化用 [prettier](https://prettier.io/)。压缩 JavaScript 用 [uglify-js](https://github.com/mishoo/UglifyJS)，它会压缩并混淆局部变量名；压缩 CSS 用 [csso](https://github.com/css/csso)，只去注释与空白、不合并规则；压缩 JSON 直接走 `JSON.parse` + `JSON.stringify`，所以 JSONC 里的注释与尾随逗号会被去掉。缩进跟随思源的「代码块 Tab 空格数」。

TypeScript、JSX、SCSS、LESS、HTML、YAML、Markdown 没有可靠的浏览器内压缩实现，所以只提供格式化。

## 快捷键

| 按键 | 作用 |
| --- | --- |
| `Ctrl+S` / `Cmd+S` | 保存当前编辑器里的文件，可改键 |
| `Ctrl+F` / `Cmd+F` | 打开文件内搜索面板，已经打开时收起 |
| `Ctrl+W` / `Cmd+W` | 思源自己的「关闭页签」；有未保存改动时会先确认 |

## 已知限制

这些都是插件 API 的边界，不是遗漏。

- **关闭确认只覆盖一部分路径。** 页签的关闭按钮、关闭快捷键与双击页签会先问；页签右键菜单里的关闭、批量关闭与退出整个思源都拦不到，这些由暂存兜底——下次打开同一文件时会问要不要恢复。
- **超过大小上限的文件打不开，也没法把点击交回思源。** 接管必须同步发生，而体积要先问过内核；超大文件会开一个页签说明原因，并指引用链接右键菜单里的「使用默认程序打开」。
- **加密笔记本里的资源会被拒绝。** 内核会把它解析成临时目录下的明文副本，写回那份副本等于静默丢弃改动。
- **大文件会慢一拍。** 整篇高亮一次超过 8 ms，就改成停止输入后再补算，颜色稍晚一步落定；格式化与压缩在主线程上算，几 MB 的文件会让界面停顿几秒。
- **不检测外部改动。** 文件被其它程序改过，要重新打开页签才看得到。
- **补全只到词级。** 候选是当前语言的关键字与文档里已有的词；没有语法树，所以没有类型信息、成员补全或跨文件补全。
- **浏览器里有两条路径只能交给浏览器。** `Ctrl+W` 关的是浏览器自己的标签页，页签关闭确认与暂存在那条路径上都来不及跑，只能靠 `beforeunload` 弹浏览器的通用确认框；非 HTTPS 环境下右键菜单的「粘贴」会置灰，正文里按 `Ctrl+V` 不受影响。
- **移动端没有页签，也没有修饰键。** 编辑器挂在铺满屏幕的弹窗里，关闭只能点操作条最左边的 ×，返回键与系统手势由暂存兜底；接管一律按单击处理。
- **浮层没有关闭按钮，独立窗口也只能用浮层。** 浮层的外壳是思源原生对话框，只去掉了右上角的 ×，关闭靠 `Esc` 或点浮层外的空白（有未保存改动先确认）；思源弹出的独立窗口没有页签栏，一律用浮层，与「桌面端形态」的设置无关。

## 开发

```
npm install
npm run dev        # 监听构建
npm run typecheck  # tsc --noEmit
npm run build      # vite build，然后在仓库根目录产出 package.zip
npm run icon       # 重新生成 assets/icon.png 与 assets/preview.png
npm run preview    # 仅按 assets/preview.html 重拍 assets/preview.png
```
